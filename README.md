# Genesis B&P simulation

This repository contains some test scripts to get familiar with [Genesis](https://genesis-embodied-ai.github.io/) A Generative and Universal Physics Engine for Robotics and Beyond.

This tests are found in test folder. The main script here is a Ball and Plate simulation. The ball is controlled by a PID controller.

## Installation

Using conda, you can create an environment from the environment.yml file:

```bash
conda env create -f environment.yml
```

## Usage

To run the simulation, you can use the following command:

```bash
python ball_and_plate.py
```
